# 关于 Git Onboard

这个站点诞生于一次真实的踩坑经历。

笔者在第一次尝试用 Git 管理项目、部署 GitHub Pages 时，遇到了安装选项搞不懂、Actions 报错找不到原因、图标和样式不生效等各种问题。为了不让后来的新手重复同样的弯路，就把整个过程整理成了这份图文教程。

## 目标读者

- 完全没有 Git 经验的学生和开发者
- 想用 GitHub Pages 部署个人网站但不知从何下手的人
- 希望养成规范版本控制习惯的新手

## 主要内容

- Git 安装与基础配置
- 本地仓库与远程仓库的连接
- 提交、推送、拉取的日常 workflow
- GitHub Pages 自动部署
- 常见问题排查

## 特别说明

本教程中的截图来自 Windows 11 + Git 2.55.0 的安装和配置过程。如果你的界面略有不同，通常不影响理解，按提示选择最接近的选项即可。

如果你发现内容有误或希望补充某个主题，欢迎在 GitHub 仓库提交 Issue 或 Pull Request。
