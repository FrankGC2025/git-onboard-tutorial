# Git 新手上船

这是一份给完全没有 Git 经验的人的教程。我们会用图文结合的方式，带你走完一条完整的上手路径：

1. **为什么需要 Git** —— 先理解问题，再学工具。
2. **安装 Git** —— 在 Windows 上下载并配置。
3. **创建第一个仓库** —— 用 Git Init 和 GitHub 新建仓库。
4. **提交与推送** —— 学会 add、commit、push 的黄金组合。
5. **部署 GitHub Pages** —— 让你的静态网页上线。
6. **日常运维** —— pull、分支、冲突排查与好习惯。
7. **用 ChatGPT 协作** —— 让 AI 阅读、修改并通过 Pull Request 提交 repository 变更。
