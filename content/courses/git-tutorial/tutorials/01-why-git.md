# 01 为什么需要 Git

在学会任何命令之前，先问自己一个问题：**我为什么要用 Git？**

## 没有版本控制的世界

想象一下你正在写一份期末论文：

- `论文_初稿.docx`
- `论文_修改版.docx`
- `论文_最终版.docx`
- `论文_最终版_真的.docx`
- `论文_最终版_真的_不改了.docx`

过了几天，你完全不知道哪个版本才是"真的最终版"。如果你想回到三天前的某个写法，只能凭记忆手动改回来。

## Git 能帮你做什么

| 痛点 | Git 的解决方案 |
|------|----------------|
| 文件越改越多，版本混乱 | 每次改动生成一个清晰的"快照"（commit） |
| 想回退到某个旧版本 | `git checkout` 或 `git reset` 一键回退 |
| 多人同时修改同一文件 | 分支（branch）+ 合并（merge） |
| 换了电脑想继续工作 | 推送到 GitHub，任何地方都能拉取 |
| 想展示作品 | GitHub Pages 免费托管静态网页 |

## Git vs GitHub

这是新手最容易混淆的两个概念：

| Git | GitHub |
|-----|--------|
| 本地版本控制工具 | 远程代码托管平台 |
| 可以在没有网络时使用 | 需要网络 |
| 负责记录历史、分支、合并 | 负责备份、协作、发布 |

**一句话**：Git 是工具，GitHub 是放代码的仓库。

## 本教程的目标

学完本教程后，你应该能够：

1. 在 Windows 上安装并配置 Git。
2. 创建本地仓库并连接到 GitHub。
3. 用 `add`、`commit`、`push` 管理你的代码。
4. 用 GitHub Actions 自动部署静态网页。
5. 处理日常开发中的常见场景。
